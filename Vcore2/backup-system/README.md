# VCore SecondBrain Backup System

Nightly automated backup of `/SecondBrain` to an external drive. 30-day rolling history. macOS launchd scheduling at 2:00 AM.

## Quick Start

```bash
cd Vcore2/backup-system
chmod +x backup.sh restore.sh install.sh
./install.sh
```

The installer will ask for:
1. Your SecondBrain path (default: `/SecondBrain`)
2. Your external drive path (e.g. `/Volumes/Samsung_T7/VCoreBackups`)
3. How many days to keep (default: 30)

---

## Files

| File | Purpose |
|------|---------|
| `backup.sh` | Main backup script |
| `restore.sh` | Restore from any snapshot |
| `install.sh` | Installs launchd job + writes config |
| `.backup-config` | Auto-generated by installer (gitignored) |

---

## Manual Commands

```bash
# Run backup now
./backup.sh

# Dry run (see what would happen, no files written)
./backup.sh --dry-run

# List available backups
./restore.sh

# Restore a specific date
./restore.sh 2026-05-01

# Restore the most recent backup
./restore.sh latest

# Restore dry run
./restore.sh latest --dry-run
```

---

## What Gets Backed Up

Everything in `/SecondBrain`, excluding:
- `*.pyc` and `__pycache__/`
- `.DS_Store`
- `*.tmp`

The SQLite database (`data/vcore_chat.db`) is included — all conversation history is preserved.

---

## Backup Structure

```
/Volumes/YourDrive/VCoreBackups/
├── 2026-03-22/
│   ├── AgentMemories/
│   ├── SharedKnowledge/
│   ├── ConversationHistory/
│   ├── Skills/
│   └── .backup-manifest.txt     ← date, file count, size
├── 2026-03-23/
│   └── ...
└── ... (30 days retained)
```

Each day is a full snapshot (via rsync `--delete`), so any day can be restored independently. Old backups beyond 30 days are automatically removed.

## Logs

```
/SecondBrain/Logs/
├── backup.log         ← main backup log (all runs)
├── restore.log        ← restore operations
├── rsync_*.log        ← per-run rsync detail
├── backup-stdout.log  ← launchd stdout
└── backup-stderr.log  ← launchd stderr
```

## Manage the Scheduled Job

```bash
# Check if job is running
launchctl list | grep vcore

# Stop the job (until next boot)
launchctl unload ~/Library/LaunchAgents/com.vcore.secondbrain.backup.plist

# Restart the job
launchctl load ~/Library/LaunchAgents/com.vcore.secondbrain.backup.plist

# Uninstall completely
./install.sh --uninstall
```

---

## Restore Workflow

1. Check what's available: `./restore.sh`
2. Dry run: `./restore.sh 2026-05-01 --dry-run`
3. Confirm and restore: `./restore.sh 2026-05-01`
4. The restore script automatically saves a snapshot of your current `/SecondBrain` to `/tmp/` before overwriting, so you can recover if something goes wrong.

---

## If the External Drive Isn't Mounted

The backup job will log an error and abort — it will not write to a fallback location silently. Check the log at `/SecondBrain/Logs/backup.log` or `backup-stderr.log`.

Mount your drive and run `./backup.sh` manually to catch up.
